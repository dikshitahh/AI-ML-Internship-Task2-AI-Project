# AI-ML-Internship-Task2-AI-Project

# Student Performance Prediction using Decision Tree Classifier

# Project Overview

The objective is to predict students' academic performance using the Decision Tree Classification algorithm based on demographic, academic, and behavioral features.

The project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), model training, evaluation, and insight generation.


# Objective

The objective of this project is to build a machine learning model that can classify students into different performance categories (Low, Medium, and High) based on their educational and behavioral data.


# Dataset

- Dataset Name: xAPI-Edu-Data
- Total Records: 480
- Total Features: 17
- Target Variable: Class (Low, Medium, High)

The dataset includes information related to student attendance, classroom participation, learning resource usage, parental involvement, and demographic details.


# Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

# Project Workflow

- Imported required libraries
- Loaded the dataset
- Performed data exploration
- Checked for missing values
- Removed duplicate records
- Conducted Exploratory Data Analysis (EDA)
- Encoded categorical features using Label Encoding
- Split the dataset into training and testing sets
- Trained a Decision Tree Classification model
- Evaluated the model using Accuracy Score, Classification Report, and Confusion Matrix
- Identified important features affecting student performance
- Generated insights and conclusions


# Model Performance

Algorithm: Decision Tree Classifier
Accuracy: 64.58%

Evaluation metrics used:

- Accuracy Score
- Classification Report
- Confusion Matrix
- Feature Importance

# Key Insights

- Students who visited learning resources more frequently generally achieved better academic performance.
- Regular attendance positively influenced student success.
- Active classroom participation through raised hands and discussions contributed to improved academic performance.
- Students who frequently viewed announcements were generally more engaged in learning.
- Behavioral and engagement-related features had a greater impact on student performance than demographic characteristics.
